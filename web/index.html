지금 업데이트

뉴스 수집·요약은 GitHub Actions에서 실행됩니다. 이 페이지는 누구나 볼 수 있으므로, 실행은 저장소 주인만 할 수 있게 되어 있습니다.

방법 1. GitHub에서 직접 실행

GitHub Actions 열기 → "Run workflow" 버튼을 누르세요. 3~4분 뒤 이 페이지에 반영됩니다.

방법 2. 이 버튼으로 바로 실행 (토큰 한 번 등록)

  1. GitHub 토큰 만들기 (Fine-grained token)
  2. Repository access → Only select repositories → 이 저장소
  3. Permissions → Actions: Read and write (다른 권한은 주지 않음)
  4. 만든 토큰(github_pat_…)을 아래에 붙여넣고 저장

토큰은 이 브라우저에만 저장되고 어디에도 올라가지 않습니다. 공용 컴퓨터에서는 저장하지 마세요.
